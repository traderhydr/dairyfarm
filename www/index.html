Mobile App Setup

Install on Android & iPhone (iOS)

This app is pre-configured with full-screen mobile icons and offline browser storage.

1. Instant Install on iPhone (iOS — No App Store Needed)

iPhones do not use .apk files. Instead, open this HTML file in Safari on your iPhone, tap the Share icon (square with arrow pointing up), and tap "Add to Home Screen". It installs with the custom Dairy Farm icon and opens full-screen like a native iOS app.

2. Instant Install on Android (Chrome Home Screen App)

Open this app in Google Chrome on your Android phone, tap the 3-dot menu (⋮) in the top-right corner, and tap "Add to Home screen" or "Install app".

3. Generate a Native Android .apk File

Use the downloadable dairy_farm_mobile_app_package.zip bundle: upload it to GitHub (where the included GitHub Actions workflow automatically compiles a downloadable .apk file for free) or run npx cap add android in Android Studio.
